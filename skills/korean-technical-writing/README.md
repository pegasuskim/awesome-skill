# korean-technical-writing

`experimental/technical-writing/`(pstack의 `technical-writing` 스킬)을 한국어
문서에 맞게 고친 스킬입니다. `skills/install.sh`가 Claude Code와 Codex에
설치합니다.

## 원본과 다른 점

- 그대로 둔 것: 문서 유형 구분(Diátaxis), 리듬, 구체적으로 쓰기, 조건을 먼저 쓰기,
  한 문장에 한 생각, 이름 하나로 부르기
- 한국어 규칙으로 바꾼 것: 쉬운 단어, 독자 지칭, 수동태, 문장 길이, 부정과
  "만"의 범위, 대명사
- 뺀 것: 관사, "-ing", serial comma, sentence case, "(s)" 복수형
- 새로 넣은 것: 문체 통일, 번역투, 영어 용어 표기와 조사, 한국어 AI 말투 목록
- `unslop` 스킬을 참조하지 않고 필요한 규칙을 본문에 넣었습니다.
- 원본은 사용자가 직접 불러야 실행되지만, 이 스킬은 모델도 불러 쓸 수 있습니다.

규칙은 영어로, 예시와 금지 표현은 한국어로 썼습니다.

## 아직 확인하지 않은 것

- 한국어 문서에서 원본이나 스킬 없는 경우보다 나은 결과를 내는지
- 문장 길이 기준(지시문 60자, 일반 문장 80자)이 적절한지
- 한국어 AI 말투 목록이 실제 출력과 맞는지
- 지시문을 한국어로 쓰면 결과가 달라지는지
