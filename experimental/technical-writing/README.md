# technical-writing

[cursor/plugins](https://github.com/cursor/plugins)의 pstack 플러그인에 있는
`technical-writing` 스킬을 써 보기 위해 가져온 복사본입니다. 아무것도 설치하지
않습니다.

- 원본: `pstack/skills/technical-writing/SKILL.md`
- 커밋: `ccb5507cec1546dc88135c1139c811e6c59115ba`
- 라이선스: MIT (`LICENSE`는 `pstack/LICENSE`를 그대로 복사)

`SKILL.md`는 원본을 수정하지 않았습니다. 본문은 pstack의 `unslop` 스킬을 함께
적용하라고 하지만 `unslop`은 가져오지 않았습니다. frontmatter의
`disable-model-invocation: true` 때문에 설치하더라도 `/technical-writing`으로만
실행됩니다.
